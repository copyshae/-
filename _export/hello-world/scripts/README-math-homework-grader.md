# 數學習作／試卷批改：一人一檔、一檔一檔來（最後用 Gemini 依正確答案自動批）

## 開始時批閱方式（預設＝Gemini API 自動）

1. **載入正確答案**（可多檔）→ **自動批改必備**（沒答案不能自動批）  
2. 選擇批閱方式：
   - **請 Gemini 自動批閱（API＝真正自動）** ← **預設／建議**  
   - **請 Gemini 自動手寫加強（API）** ← 字跡差時用  
   - **請 Gemini 網頁…（要手動貼）** ← 只開網頁，**不會自動批**  
   - Cursor／自己對照：備用

### 用 Gemini 依正確答案自動批（免手動貼檔｜建議試發座號 00）

1. **載入正確答案**（答案 PDF／圖／文字）  
2. 到 https://aistudio.google.com/apikey 用 Google 帳號建立 **API key**  
   （與網頁 Gemini Pro **訂閱分開**；沒有 key＝無法自動）  
3. 習作批改 → **Gemini金鑰** → 貼上儲存（`MathGrading\gemini-api-key.txt`，不上傳 GitHub）  
4. 確認批閱方式是 **「請 Gemini 自動批閱（API＝真正自動）」**  
5. 按鈕：
   - **依答案·Gemini自動批** → 對照答案批目前這份，存註記後可選下一位  
   - **連續自動批** → 從目前未批起，**依序自動批完所有未批**（每份成功自動存檔）  
6. 程式用 **gemini-2.5-flash** 送出學生卷＋**全部**正確答案＋提示  
   → 回覆填入右側並存 `輸出\00-Gemini回覆.md`

> **為何以前自動不起來？**  
> 舊版預設模型 `gemini-2.0-flash` 已於 **2026-06-01 下線**。本版改為 `gemini-2.5-flash`。  
> 另：「網頁批閱」只會開瀏覽器，仍要你手動 Ctrl+V＋上傳圖，**不是自動**。  
> **沒有正確答案就不能自動批**——AI 必須對照答案給分。

### 用 Gemini 網頁批（手動，非自動）

1. 選「請 Gemini 網頁…」→ 開始批  
2. 瀏覽器開 Gemini → `Ctrl+V` 貼提示 → **上傳** 試卷  
3. 回覆貼回程式右側 →「輸出此生PDF」

全班經 AI（Gemini／Cursor）＋老師反覆確認後，按 **全班學習總表** 產出給導師／家長：
- `全班學習狀況總表.pdf` / `.md` / `.csv`
- 含程度分布、常見課題、需關注座號、逐座號一覽（以座號、不含姓名）

每位輸出 PDF／註記末段固定含：
- **個別診斷結果**（弱點、是否跟上）
- **程度**：跟上／略落後／明顯落後／需補先備
- **練習依程度**：
  - **跟上（好的學生再提升）**：少鞏固 → 靈活 → **再提升挑戰（必做）** → 超前伸展（選做）
  - 略落後／明顯落後／需補先備：**多次補齊**（每次 1 點、少題）→ 先有成就 → **漸次跟上**
- **練習發放（省紙）**：
  - **預設**：Gemini／Cursor／本程式**自動產練習題＋自學指導＋建議影片連結**（不用均一）
  - 發：班級群組；回：個別傳老師
  - 沒裝置才列印包

## 資料夾（桌面\MathGrading）

```
標準答案\     ← 載入的正確答案（自動批必備）
輸入\         ← 學生試卷（一人一檔）
練習回傳\     ← 學生回傳 05-R01.jpg／.pdf
輸出\         ← 00-註記.md、00-Gemini回覆.md、批閱 PDF
練習歷程\     ← 多次回傳與進步
```
