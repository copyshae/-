# 兩台電腦＋手機同步

習作批改／習作台**沒有自動雲端同步**。跨裝置請用 JSON 匯出／匯入，或把電腦工作資料夾整夾放 OneDrive。

## 快速對照

| 資料 | 匯出位置 | 檔名 | 匯入位置 |
|------|----------|------|----------|
| 批改進度 | 手機／網頁「習作批改」→ 匯出批改進度 | `習作批改進度.json` | 另一手機「匯入批改進度」；習作台「匯入批改進度.json」；電腦習作台「從批改進度檔同步」 |
| 習作台程度／發放 | 習作台 → 匯出班級資料 | `班級狀態.json` | 另一台習作台「匯入班級資料」 |
| 電腦工作夾 | — | — | 桌面 `MathGrading`、`習作台資料` 整夾放 OneDrive，兩台電腦指向同一路徑 |
| 掃描回傳 | 手機下載 PDF | — | 電腦 `習作台資料\掃描匯入` → 習作台「處理掃描匯入」 |

## 同一台手機／瀏覽器（不用 JSON）

- 習作批改與習作台若用**同一個固定網址**（加入主畫面），資料在 `localStorage`。
- 習作台按 **「本機：從習作批改同步」** 即可讀批改程度。
- 換網址、換瀏覽器、清快取 → 資料不互通，必須用 JSON。

## 兩台電腦（WinForms）

1. 安裝腳本會建立：
   - `桌面\MathGrading`（習作批改試卷、設定）
   - `桌面\習作台資料`（含 `掃描匯入`、`匯出給手機`）
2. 把這兩個資料夾移到 OneDrive，兩台電腦都從 OneDrive 開 `.vbs` 捷徑。
3. 習作台 **「從批改進度檔同步」**：選 `習作批改進度.json`（可從手機匯出後放到 `習出給手機` 或 OneDrive）。

## 手機 ↔ 手機

1. A 手機：習作批改 → **匯出批改進度** → 存到 OneDrive／LINE 傳給自己。
2. B 手機：習作批改 → **匯入批改進度（覆蓋）**。
3. 習作台程度：A 匯出 **班級狀態.json** → B 習作台 **匯入班級資料**。

## 更新程式（不是同步資料）

只更新捷徑／腳本、資料夾內 JSON 不會被刪：

```powershell
irm https://raw.githubusercontent.com/copyshae/-/cursor/textbook-grade-format-459a/_export/hello-world/scripts/refresh-desktop-vbs.ps1 | iex
```

關閉舊的習作批改／習作台視窗後，再雙擊桌面 `.vbs` 重開。

完整套用（含手機 Pages）見 `_export/hello-world/README.md` 的 `pull-export-from-dash-repo.ps1`。
