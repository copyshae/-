20260818 習作批改手機版：ChatPlayground 與貼上自動批閱

接續 0803 電腦視窗與 0817 換機安裝。手機習作批改預設走 ChatPlayground AI（終身 Unlimited）；維護時改 ChatGPT 免費版。網頁不會自己貼提示，必須「貼上自動批閱」格子才會已批。

一｜接續哪一則

  • 電腦視窗規格仍以 20260803 為準（一人一檔、程度、自產練習、發放與回傳循環）。
  • 換機安裝見 20260817。
  • 本則把 0803 之後的手機版批閱路徑連上公開學習日誌（工作日誌 0818）。

二｜今天怎麼批（手機）

  1. 打開 習作批改，用掃描王匯入試卷（檔名只要座號）。
  2. 點座號 →「ChatPlayground AI 自動批閱」（會複製提示、下載試卷、開網站）。整班用「連續 ChatPlayground 批」。
  3. 到 https://web.chatplayground.ai/ 按 Ctrl+V 貼提示並上傳試卷。
  4. 把回覆貼回頁面上方「貼上自動批閱」→ 綠色按鈕才變已批。沒貼回覆、格子會一直未批。
  5. ChatPlayground 顯示維護中時：改按「ChatGPT 免費版自動批閱」，開 https://chatgpt.com/，流程相同。免費版有用量上限；恢復後改回 ChatPlayground。
沒匯入試卷會捲到掃描區並寫明原因。網頁版 ChatPlayground／ChatGPT 沒有對外 API，無法在背景全自動寫回格子。

三｜Gemini 金鑰（選用備援）

  • 預設不必填金鑰。需要時才用「改 Gemini 自動批（需金鑰）」。
  • 測試失敗常見原因：預覽網址 raw.githack.com 被網站限制擋 Referer、429／額度、金鑰無效。不必等下個月才再試。
  • 不要把金鑰貼進對話或提交 Git。沒有現成金鑰可借用。

四｜0803 延伸已在手機版

  • 批完後續：練習模板 → 發放訊息 → 寫入習作台 → 回傳循環 → 歷程。
  • 待批／待回清單；掃描「回傳進循環」；已批練習包；無裝置列印；待認知／待重謄。
  • 所有輸出國中課本形式（全形＋－＝、禁止 LaTeX／$$）。
  • 習作台：同步程度（含待判定）、群發文一～四步驟、複製需列印座號。掃描來源寫「掃描王」。
  • 正式 PDF／整班列印包仍以電腦「習作批改」為主。

Cloud Agent 不能推 copyshae/hello-world。在桌面 hello-world 跑套用腳本後，本則與習作批改才會上 GitHub Pages。

  1. cd $env:USERPROFILE\Desktop\hello-world
  2. PowerShell：$env:DASH_EXPORT_BRANCH='cursor/textbook-grade-format-459a' 後執行 scripts\pull-export-from-dash-repo.ps1（見 dash 倉庫 _export/hello-world/README.md）。
  3. 關掉舊視窗，再雙擊桌面兩個捷徑：習作批改.vbs、習作台.vbs（不要用舊的 習作台.cmd）。
