20260804 習作台（手機可見、掃描匯入、桌面啟動）

接在 0803 習作批改之後的下一主題：把「習作台」補成可掌握、可發送、可從掃描王匯入的工作台；桌面捷徑打不開與 Gemini 404 一併修好。篇號依主題往後編，不依實際工作日。

一｜習作台要做什麼

  • 與「習作批改」分工：批改／產練習在批改視窗；掌握程度與發送用習作台（手機或桌面）。
  • 只用座號、不存姓名。試發固定 00（不占人數）。
  • 程度／發送狀態可篩選：未發、待回、需關注、先備。
  • 管道：Google 教室／通訊軟體群組；掃描來源寫「掃描王」（勿只寫 CS）。
  • 手機↔電腦用 class-state.json 匯出／匯入。

二｜手機：加入主畫面與可見性

  • PWA：favicon、manifest、加入主畫面；Share Target 可從掃描王丟檔。
  • 檔名自動帶座號與回傳次數（例 05-R01）。
  • PDF 提示、縮圖網址用完釋放，避免手機記憶體撐滿。
  • 介面全面繁體中文：Classroom→Google 教室；按鈕去掉英文品牌堆疊。
正式頁：https://copyshae.github.io/hello-world/directory/apps/teacher-desk/ （Safari 加入主畫面。Cloud Agent 不能直接推 hello-world，套用後才會變新版。）

三｜桌面：掃描匯入與捷徑打不開

  • 「處理掃描匯入」：把既有掃描匯入夾複製到「練習回傳」並標待回。
  • 補回班級資料匯出／匯入、已發→待回。
  • 現象：桌面 習作台.vbs／習作台.cmd 開不起來（路徑中文編碼、舊 install 字串沒閉合）。
  • 作法：ASCII 安裝腳本、Bypass 執行原則、絕對路徑啟動器；改完要關掉舊視窗再開。

四｜桌面習作批改：Gemini 404 與自動批

  • 根因：gemini-2.0-flash 已於 2026-06-01 下線，呼叫會 404。
  • 預設模型改 gemini-2.5-flash；預設模式 gemini_auto。
  • 有正確答案→對照批；無正確答案→直接 AI 批（都不擋）。
  • 「網頁批閱」是手動貼，不是自動；自動批需要 AI Studio API 金鑰（≠ 網頁 Pro）。

五｜供日後修正

  • 正式程式在 copyshae/hello-world 的 directory/apps/teacher-desk 與 scripts/teacher-desk-app.ps1。
  • 本倉庫 copyshae/- 只放 _export/hello-world/ 暫存；本機跑 pull-export-from-dash-repo.ps1 才上線。
  • 介面、提示、對話框必須繁體中文；掃描來源寫「掃描王」。
  • 不要提交金鑰、.env、學生姓名。
