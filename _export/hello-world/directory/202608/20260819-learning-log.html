20260819 手機 Cursor 也能用推日誌快捷詞

桌面快捷詞只裝在 Windows 的 %USERPROFILE%\.cursor。手機 Cursor 是 Cloud Agent，必須把規則放進倉庫，打「推日誌」「連日誌」才會生效。

一｜線上學習日誌在哪

  • 首頁：https://copyshae.github.io/hello-world/directory/
  • 202608：https://copyshae.github.io/hello-world/directory/202608/
  • 202607 舊路徑：https://copyshae.github.io/hello-world/directory/logs/
  • hello-world 沒開 Discussions；用法寫在 skill／規則，不是 GitHub 討論區。

二｜推日誌原本怎麼用（桌面）

  • 倉庫檔：.cursor/skills/push-learning-log/SKILL.md、.cursor/rules/push-learning-log.mdc
  • 安裝：install-push-log-shortcut.ps1 → 複製到本機 %USERPROFILE%\.cursor
  • 短語：推日誌、連日誌、日誌首頁、裝快捷詞；可 推日誌 0819
  • 202608 起檔案在 directory/YYYYMM/，不要再寫進 directory/logs/

三｜手機為什麼沒用

  • 手機 Cursor = Cloud Agent，工作倉是 copyshae/-，看不到桌機 ~/.cursor。
  • Cloud Agent 不能推 copyshae/hello-world（403）。要先寫 dash 的 _export/hello-world/，電腦再套用。
  • 先前有一篇 0819 誤放 directory/logs/；正確是 directory/202608/20260819-learning-log.html。

四｜手機現在怎麼打

  1. 手機 Cursor 開倉庫 copyshae/-，新開一個對話。
  2. 打 推日誌、連日誌、日誌首頁；或 /push-learning-log。
  3. 連日誌：對話會回可點網址（手機點開即可）。
  4. 推日誌：寫進 _export/hello-world/directory/202608/ 與 工作日誌.md，推本倉庫。正式 Pages 仍要電腦套用。
  5. 也可打開快捷詞頁長按複製：套用後網址 https://copyshae.github.io/hello-world/directory/logs/prompts/
若對話開在別的倉庫：把「說推日誌／連日誌時依 skill push-learning-log 執行」貼到 Cursor 設定 → Rules → User Rules（同一帳號會同步到手機）。

五｜同日其他工作大要（掃具台）

  • 校園掃具請領 PWA：請領、庫存（新／舊／尚可）、拍照辨識、CSV、離線備份。
  • 每次請領各一列；導師優先、班級可略；欄位可增刪；確認視窗後再寫入。
  • 正式手機網址仍走 hello-world Pages；dash 倉庫名 - 的 Pages 不可用。

六｜套用正式站（本機）

在桌面 hello-world 跑 _export/hello-world/README.md 的套用指令，本則與快捷詞頁才會上 GitHub Pages。
