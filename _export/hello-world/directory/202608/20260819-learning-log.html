20260819 掃具台上線與 CSV 匯入負數

校園掃具請領 PWA 正式放到 hello-world 的 directory/apps/scan-equip/。CSV 匯入負數（如 -2 代表扣回）不再被截成 0；同步腳本已納入掃具台，並在推送前切到 master，避免 GitHub Pages 404。

一｜掃具台新增上線

  • 路徑：directory/apps/scan-equip/
  • 正式網址：https://copyshae.github.io/hello-world/directory/apps/scan-equip/
  • 來源在 dash 倉庫 copyshae/- 的 _export/hello-world/，再套到本倉庫推 Pages。
  • 安裝／桌面腳本：scripts/install-scan-equip.ps1、scripts/scan-equip-app.ps1、scripts/README-scan-equip.md

二｜CSV 匯入負數不再變 0

  • 問題：匯入時數量若為負數（例如 -2，代表扣回）會變成 0。
  • 原因：匯入用了 Math.max(0, parseInt(...))，和手動請領可接受負數不一致。
  • 修正後：CSV 匯入保留負數，與手動請領／扣回相同。
掃具台允許負數是刻意的（扣回、修正），不要再用 Math.max(0, …) 把數量夾成 0。

三｜匯出同步腳本已支援掃具台

  • scripts/pull-export-from-dash-repo.ps1 把 scan-equip 列入下載與 git add 清單。
  • 推送前自動切到 hello-world 的 master 分支，避免 GitHub Pages 還停在別的分支而 404。
  • Pages 設定維持：Branch master、Folder / (root)。不要改成 docs。

四｜功能大要（同日已完成）

  • 請領登記、庫存（新／舊／尚可）、拍照／分享辨識、CSV 匯出匯入、離線備份。
  • 每次請領各一列；導師優先、班級可略；欄位可增刪；確認後再寫入。
  • 只用導師／班級／處室名稱作領用人，不把學生姓名寫進檔名與日誌。
