20260805 手機習作批改自動批與批完後續

接在 0804 習作台之後：手機版先前只會複製提示、不會真的批；改接 Gemini API、對齊 0803 批完後續，並因 - 倉庫 Pages 不可用改匯出到 hello-world。篇號依主題往後編，不依實際工作日。

一｜卡住「批改中」→ 改為 API 自動批

  • 現象：00 試發整天停在批改中，01–35 未批，提示預覽空白。
  • 根因：舊手機版不會呼叫 Gemini API；按「貼上批」只標成批改中，沒有完成回寫。
  • 手機設定 AI Studio API 金鑰（存在本機，不進 Git）。
  • 可選匯入正確答案；匯入試卷後「Gemini自動批／連續自動批」；批完標已批並寫回覆。
  • 「批改中→未批」一鍵解除卡住。

二｜加速：快速批與連續批

  • 預設「快速批」：精簡提示、gemini-2.5-flash-lite、限制輸出長度。
  • 匯入時壓縮大圖（最長邊 1600、JPEG）。
  • 連續批：答案 base64 只編一次；快速模式可雙線並行。
  • 檔名座號自動對應；頂部「一鍵連續批」；螢幕喚醒鎖。

三｜批完後續（對齊 0803）

  • 依程度給練習模板：跟上／略落後／明顯落後／需補先備。
  • 自產練習說明（不用均一；影片用 YouTube 搜尋頁）。
  • 複製此生發放訊息、寫入習作台程度、開啟習作台。
  • 練習回傳循環：分數／問題點／回饋／下一輪 → 存歷程、下載練習 HTML。
  • 習作台「今日流程」同步說明。
正式 PDF、整班數位練習包、無裝置列印包仍以電腦「習作批改」為主。規格對照： 20260803 學習日誌

四｜Pages 不可用 → 改匯出 hello-world

  • 倉庫名 - 的 GitHub Pages（Actions 或 docs）多次失敗／找不到可用網址。
  • 使用者也被 raw.githack 英文中轉頁卡住。
  • 作法：手機習作批改／習作台放到 _export/hello-world/；本機跑 pull-export-from-dash-repo.ps1 套到桌面 hello-world 並推 Pages。
  • 匯出來源改為 main，避免刪分支後下載失敗；套用後自動推 hello-world Pages。
  • 無快取網址：docs/td（習作台）、docs/mg（習作批改）。
正式手機批改：https://copyshae.github.io/hello-world/directory/apps/math-grader/

五｜金鑰、503、免費額度

  • 測試金鑰：換鑰後常因貼不完整、貼成網頁訂閱字串、新鑰未開通而失敗；儲存前先測，並清誤貼空白／引號。
  • 503／忙碌：同模型重試 3 次再換模型；提示改為建議稍後再批（不要說成金鑰錯）。
  • 免費額度用盡：解析 retry 秒數再等；連續批改單線、份與份之間稍停。結尾勿寫「請確認網路與金鑰」。

六｜進度備份與開啟方式

  • 習作批改進度雙重備份：關掉再開可自動恢復已批座號。
  • 主畫面網址必須相同才讀得到同一份進度；可匯出／匯入進度。
  • 習作台可從習作批改同步程度。
