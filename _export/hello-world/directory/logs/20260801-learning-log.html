20260801 LINE 轉發雛形與看診備忘歸檔

近日主線：釐清 LINE 群發／中繼轉發只能走官方帳號 Bot；另把手機對話重點整理成可開、可複製的個人備忘（細節不進公開學習日誌）；並用快捷詞 tui-ri-zhi 收工推日誌。

一｜LINE 群組廣播轉發雛形

  • 結論：沒有「個人帳號中繼群自動轉多群」；也不能代為操作手機 LINE 個人帳號。
  • 合法做法：LINE 官方帳號 + Messaging API webhook，把來源群訊息轉到勾選的目標群。
  • 產出目錄：line-group-forwarder/（webhook、管理後台、README）。
  • 倉庫：copyshae/- 分支 cursor/line-group-forwarder-7fb6。
  • Draft PR：#3 Add LINE group broadcast forwarder（尚未合併）。

二｜LINE 對話摘要 → 個人看診備忘

  • 依使用者貼上的 LINE 匯出文字，先做對話重點，再整理成個人眼科看診注意事項與時程備忘。
  • 產出：工作日誌.md（首頁互連）、眼科看診紀錄-正本.md。
  • 分支：cursor/ophthalmology-visit-notes-b6ec；Draft PR #4。
  • 手機可開 GitHub 檔案頁長按複製；無法直接寫入手機「備忘錄」App。
公開學習日誌只記「有歸檔、在哪個 PR」；看診細節與健康資訊留在該 draft 分支／本機，合併前請自行確認分享範圍。
