六｜iPhone「檔案」餘檔（手動）
  1. 打開 檔案 App →「最近項目」或「瀏覽」。
  2. 搜尋：Recorder、錄音、掃具、庫存、請領、scan。
  3. 長按不需要的檔 → 刪除。已刪 App Recorder 後，餘檔常仍留在「檔案」。
  4. 到「最近刪除」再清一次，空間才真正釋放。
  5. 留下：試題、fund 備份、已匯出的 JSON／Excel。
七｜照片 App 截圖（手動）
  1. 打開 照片 → 搜尋 螢幕截圖 或 Screenshot。
  2. 也可搜尋 Cursor、github、copyshae 找相關畫面。
  3. 選取後刪除 → 再到「最近刪除」清空。
  4. Android：Google 相片／檔案 → 螢幕截圖相簿，刪完再清垃圾桶。
八｜Safari 網站資料（仍不足時）
  1. 設定 → Safari → 進階 → 網站資料。
  2. 搜尋並刪除 copyshae.github.io（必要時也清 github.io）。
  3. 關閉相關分頁後，用 Safari 重新開啟本頁或各工具。

這一步等於重置此站本機資料，請先匯出購物帳／掃具／批改進度。
