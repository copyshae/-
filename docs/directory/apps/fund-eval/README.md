# 基金評估台｜網路搜尋欄位清單

用來從公開網站（基金資訊觀測站、Morningstar、Lipper、投信官網、銀行基金頁）蒐集資料，填進「基金評估台」後自動算進出場訊號。

## 一、識別（必備，對應 A–D）

| 欄位 | 說明 | 搜尋關鍵字建議 |
|------|------|----------------|
| 基金代碼 | 台灣銀行／通路代碼（如 B09463） | `B09463 基金` |
| 基金名稱＋級別 | 含幣別、配息／累積、避險 | 完整法定名稱 |
| ISIN | 國際代碼，跨站對照最準 | `ISIN 貝萊德世界黃金` |
| 計價幣別 | USD／EUR／TWD／AUD 等 | 級別說明 |
| 避險與否 | 對沖級別會影響淨值路徑 | `對沖` `H1` `Hedged` |
| 資產類別 | 黃金／科技股／HY／新興債／平衡… | 決定用哪個總經指標 |
| 配息政策 | 累積、穩定配息、固定月配、總報酬配息 | 影響「本金比」重要性 |

## 二、價格與位階（進出場核心，對應 E–I）

| 欄位 | 用途 |
|------|------|
| 最新淨值＋淨值日期 | E；務必對齊同一交易日 |
| 52 週最高／最低 | F／G；或由近一年淨值序列自算 |
| 近 250 個交易日淨值（或年線） | 算 250MA → **I 年線偏離度** |
| （可選）近 3／5 年淨值 | 判讀長期結構，非短訊必要 |

**自算公式**

- H 52 週位階% = (E − G) ÷ (F − G) × 100  
- I 年線偏離% = (E − 250MA) ÷ 250MA × 100  

## 三、配息監控（月配／穩定配息必抓，對應 J–M）

| 欄位 | 為何重要 |
|------|----------|
| 每單位配息 J | 最近一期實際配發 |
| 配息頻率／除息日 | 月配、季配；對齊比較 |
| 年化配息率 K | 或用 J × 次數 ÷ 淨值 |
| **配息來自本金比例 L** | 台灣穩定／固定月配的關鍵風控；持續攀升 → 減碼訊號 |
| 上次本金比（歷史） | 判斷「持續攀升」 |
| 近一年含息總報酬 M | 若 M 遠低於 K，常代表配息侵蝕本金 |

## 四、總經先導（對應 N–P，依資產類別選）

| 資產類型 | 建議連動指標 N | 要記的數值 O |
|----------|----------------|--------------|
| 黃金 | 現貨金價 XAUUSD | 價位、是否突破前高／阻力 |
| 全球／科技股 | Nasdaq-100、MSCI World IT | 指數位階、本益比區間 |
| 環球／美非投等債 | Bloomberg HY OAS、ICE BofA HY | 利差 bp；收斂＝偏買、過緊＝減碼 |
| 新興債／邊境債 | EMBI、CEMBI、EM HY | 利差 bp、美元指數 |
| 房貸／MBS 收益 | MBS 利差、美債殖利率 | 利差與存續期風險 |
| 多元收益／收益成長 | HY 利差＋股市波動 | 股債風險偏好 |
| 基礎建設／公用事業 | 基建指數、實質利率 | 利率敏感度 |

評估狀態 P 由程式依規則自動標：**加碼／續抱領息／減碼警戒**。

## 五、建議搜尋來源（繁中情境）

1. 基金資訊觀測站（代碼、ISIN、淨值、報酬）  
2. 銀行基金頁／投信月報（配息組成、本金比）  
3. Morningstar／Lipper（含息報酬、同級比較）  
4. 總經：FRED、Bloomberg 公開摘要、各大投行 HY OAS 圖  

## 六、最小可分析組合（先求有再求好）

每檔至少湊齊：

1. 代碼＋名稱＋幣別＋資產類別  
2. 最新淨值、52 週高、52 週低  
3. 250MA（或 250 日淨值）  
4. 若為配息級別：年化配息率＋**本金比例**＋一年含息報酬  
5. 一項對應的總經指標數值（利差 bp 或金價／指數）  

湊齊後即可在評估台篩「買進訊號／減碼訊號」。
