20260906 太陽心語圖片收錄 PWA

接日誌 0905 導師影音圖書館。本日推上太陽心語圖片收錄：網路搜尋＋種子語錄、美聲朗讀或無聲瀏覽，並優先顯示網路原圖。

手機立刻可開（免開電腦）：
https://copyshae.github.io/-/directory/202609/20260906-learning-log.html
正式 hello-world： https://copyshae.github.io/hello-world/directory/202609/20260906-learning-log.html

一｜入口

  • 完整版：https://copyshae.github.io/-/taiyang-xinyu/
  • 簡易版：simple/
  • 建目錄：scripts/build-taiyang-xinyu-catalog.py；朗讀對照 data/taiyang-xinyu-read-overrides.json

二｜瀏覽與朗讀

  • 點選切換圖片、上一則／下一則、搜尋分類。
  • 美聲朗讀（共用 tts-voices.js）或無聲模式；原圖只唸圖上內容。
  • 有 imageUrl 時優先網路原圖，失敗再 fallback 本站鏡像／卡片。
