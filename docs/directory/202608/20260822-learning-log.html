20260822 看書／看文件（doc-reader）

接日誌 0821 七個好習慣分類。本日把尚未上線的「看書／看文件」App 與後續修正一次推上日誌：拍照／檔案／網址／貼上 → 中英讀誦 → 英文可逐句或全文譯中並朗讀 → 節錄四面向建議 → 可疊加七習慣今日紀錄。

手機立刻可開（免開電腦）：
https://copyshae.github.io/-/directory/202608/20260822-learning-log.html

一｜入口

  • 主版（建議）：https://copyshae.github.io/-/doc-reader/
  • 鏡像：https://copyshae.github.io/-/directory/apps/doc-reader/
  • 習作工具主頁：https://copyshae.github.io/-/ →「打開看書／看文件」
  • 七習慣分頁「看書文件」：https://copyshae.github.io/-/habits-7/
  • 電腦版嵌入：https://copyshae.github.io/-/life-desk/（看書／看文件分頁）
  • 來源路徑：docs/doc-reader/（Service Worker 目前 doc-reader-v11）

二｜匯入與辨識

  • 拍照／相簿、PDF、TXT／MD、網址、貼上文字（獨立視窗，CSV 自動整理成易讀格式）。
  • 英文照片 OCR 後可選翻譯；幾乎無文字（純圖）改走 Google／Bing／Yandex 圖搜跳出視窗。
  • 所有輸入可取消、重新選其他檔案。

三｜讀誦與英文翻譯（v11）

  • 中文／英文：念本頁、連續念；可暫停／取消。
  • 偵測到英文時跳出選項：
    1. 中英逐句翻譯＋朗讀（每句先念英文、再念中文）
    2. 全文翻譯中文＋朗讀
    3. 保留英文原文
    4. 整篇中英對照陳列
  • 英文念完後，選單自動改為中文翻譯選項；中文內容仍保留「譯成英文」學習模式。
  • 中英學習視窗：逐句對照、點英文生字查解釋、圈選中文查萌典／維基／Gemini。

四｜圈選查字（含 iPhone 修正）

  • 長按圈選 → 綠色「已記住圈選」→ 再按「查解釋」（請勿連按）。
  • iPhone：圈選快取、touchend 觸發，避免誤判「請先圈選」。
  • 主閱讀區英文可點單字查解釋；解釋視窗可讀誦、開網路辭典。
  • 讀誦結束不會自動關閉視窗；僅按暫停／取消或關閉才消失。
  • 防連按約 650～800ms，避免按太快看不清。

五｜節錄重點與七習慣整合

  • 看完／聽完可「節錄重點與建議」：①身心靈／靈命　②數學課程　③衛生組　④其他可行動。
  • 可念節錄；可「疊加建議到七習慣今日紀錄」（habits7-v1，習慣7／Ⅱ象限）。
  • 七習慣頁開著時，storage／focus 事件會自動刷新今日紀錄。
  • 選填 Gemini 金鑰可提升節錄與翻譯品質（僅存本機）。

六｜若仍見舊版

Safari：設定 → 進階 → 網站資料 → 刪除此站 → 重新開啟 doc-reader。舊版會出現 alert「請先圈選」；新版改為綠色預覽＋狀態列提示。
